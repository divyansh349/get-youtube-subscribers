Get YouTube subscribers

The APIs provided by this application include the following:

  • GET /subscribers: Returns Json data array of all subscribers in the database.
  • GET /subscribers/names: Returns Json data array of subscribers with only two fields name and subscribedChannel
  • GET /subscribers/:id: Returns the details of a subscriber with the given ID.
  • If ":id" in /subscribers/:idnot found in database, it returns an error message with a status code of 400.
